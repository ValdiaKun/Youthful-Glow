# Youthful V2

Personalized iOS appearance/habit tracker.

V2 adds:
- Daily routine and consistency tracking
- Sleep, water and workout logging
- Progress dashboard
- Private monthly progress photos stored locally
- Product tracker
- Reminders
- Personalized grooming/skincare plan
- SwiftData persistence

Suggested deployment target: iOS 17+

Important distribution note:
The source project can be built with Xcode/Xcode Cloud. Apple requires an appropriate Apple Developer Program account for TestFlight/App Store distribution. TestFlight builds must be uploaded to App Store Connect; external testing may require TestFlight App Review.
